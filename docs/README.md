# Nigredo-Dokumentation

- [Neue Referenz erstellen](./neue-referenz-erstellen.md): Ablauf, Datenmodell,
  Bildaufbereitung und Qualitätsprüfung für Case Studies.
- [Site Guardrails](./site-guardrails.md): verbindliche technische Prüfungen für
  Build, Metadaten, Bilder und strukturierte Daten.

  (`src/styles/stil-2026.css`).
- [Optimierung 28.10.2026](./optimierung-2026-10-28.md): Aufräumen, SEO, KI-Bots und Ladezeit.
- `nigredo-seo-geo-audit.docx`: bestehender SEO-/GEO-Audit als fachliche Referenz.

`public/` ist eine generierte Build-Ausgabe. Quellinhalte liegen in `src/`, statische
Dateien in `static/` und die benötigten Bildmaster in `assets-src/referenzen/`.
